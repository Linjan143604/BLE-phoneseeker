

# ESP32 BLE/WiFi 巡逻探针

一个基于 ESP32 的便携式设备探测工具，使用 WiFi 探针或 BLE 扫描来探测附近的手机、手表、耳机等设备，并通过 OLED 屏幕实时显示信号强度。适用于宿舍巡逻、抓带手机的学生等场景。

## 功能特性

- **双模式探测**：支持 WiFi 探针（Probe Request）和 BLE 扫描两种模式
- **实时信号显示**：OLED 大字显示 RSSI 信号强度（dBm）
- **信号进度条**：底部可视化进度条，一眼看清信号强弱
- **信号等级**：STRONG / MIDDLE / WEAK / NO SIGNAL 四级判定
- **突变报警**：当信号比背景值突然升高时，屏幕反白显示 `TARGET!`
- **MAC 地址列表**：一键查看探测到的设备 MAC 地址，按信号强度排序
- **后台扫描**：查看列表时持续扫描，数据实时更新
- **按键交互**：短按翻页/进入列表，长按切换模式
- **启动动画**：开机显示 Logo 和加载进度条
- **完全离线**：不联网、不上传数据，所有处理在本地完成

### 主界面

```

-58 dBm
  MIDDLE

[████████████░░░░░░░░]
```

- **第一行**：扫描状态或报警提示

## 参数调整

在代码开头的参数区可以调整：

```cpp
#define SCAN_DURATION  1       // 每次扫描时长（秒）
#define DEVICE_TIMEOUT 10000   // 设备超时移除时间（毫秒）
#define MAX_MACS       50      // 最大存储设备数
#define RSSI_STRONG   -55      // 强信号阈值
#define RSSI_MIDDLE   -65      // 中等信号阈值
#define RSSI_WEAK     -75      // 弱信号阈值
#define JUMP_THRESHOLD 8       // 突变报警灵敏度（dB）
#define LONG_PRESS_MS 500      // 长按判定时间（毫秒）
```

### 调参建议

| 场景 | 调整 | 建议值 |
|:---|:---|:---|
| 报警太频繁 | 调大 `JUMP_THRESHOLD` | 10~12 |
| 报警不够灵敏 | 调小 `JUMP_THRESHOLD` | 5~6 |
| 设备太多记不下 | 调大 `MAX_MACS` | 80（注意内存） |
| 长按太灵敏 | 调大 `LONG_PRESS_MS` | 700~800 |

## WiFi vs BLE 模式对比

| 对比项 | WiFi 探针 | BLE 扫描 |
|:---|:---|:---|
| 信号强度 | 强（约50-100mW） | 弱（约1-10mW） |
| 穿墙能力 | 强 | 弱 |
| 息屏影响 | 小 | 大（广播频率降低） |
| 干扰源 | 少 | 多（手表、耳机等） |
| 适用场景 | 探测手机本体 | 探测蓝牙设备 |

**建议**：如果主要探测手机，优先使用 WiFi 模式；如果需要探测蓝牙耳机/手表，使用 BLE 模式。

## 实战技巧

1. **关注突变，不看绝对值**：走廊背景值可能是 -75dBm，走到门口跳到 -60dBm，这个 15dB 的跳变才是关键。
2. **每个门口停留 2-3 秒**：给息屏手机留出发送广播的时间。
3. **天线朝前**：手持设备时，让 ESP32 天线朝向走廊前方，减少身体遮挡。
4. **关掉自己的设备**：巡逻前关闭自己手机的 WiFi 和蓝牙，避免干扰。
5. **校准背景值**：先在空走廊走一圈，记住背景值，再开始巡逻。

## 常见问题

**Q: 为什么探测到的信号强度一直在跳？**
A: 这是正常现象。人体遮挡、多径反射、手机省电策略都会导致信号波动。关注趋势和突变，不要盯着单个数值。

**Q: 为什么贴脸只有 -60dBm？**
A: 手机蓝牙发射功率低，且息屏后会降低广播频率。-60dBm 对于手机蓝牙来说是正常值。

**Q: 为什么设备数一直显示 30/50？**
A: 走廊里蓝牙设备很多（手表、耳机、路人手机），数量上限是防止内存溢出。数量本身没有意义，关键是信号强度的突变。

**Q: 编译报错 `esp_wifi_init was not declared`？**
A: 在代码顶部添加 `#include <esp_wifi.h>`。

**Q: 上传失败 `Failed to connect to ESP32`？**
A: 按住开发板上的 BOOT 按钮，点击上传，看到 `Connecting...` 后松开。
